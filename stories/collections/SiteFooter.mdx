# About Site Footers
The site footer is the bottom section of every page. It identifies the site and the organizations it belongs to, provides contact information and social media links, and connects visitors to University-wide resources. Every footer ends with the Notre Dame academic mark, network links, and the copyright notice. The footer is responsive and includes the light/dark mode toggle.

## Best Practices

### Site Name and Parent Organizations

The footer shows the site name followed by its parent organization. Add a grandparent organization when the site sits within a larger unit, and a secondary parent when a site is jointly owned by two units. Parent and grandparent names require a link, otherwise they will not display.

### Contact Information

Include an address, phone, and email when visitors would reasonably use them. Leave a field empty to omit it. The Notre Dame, IN city, state, and postal code are provided automatically, so enter only the street address.

### Social Media

Add only the social accounts the site actively maintains. Accounts left empty are not displayed. The University's social links and network links appear automatically and should not be changed.
