## Installing on a Site

| Asset | Download | Purpose |
|-------|----------|---------|
| `image-compare.css` | <a href="/downloads/image-compare.css" download="image-compare.css">Download</a> <small>2.4 KB</small> | Component styles. Depends on ndt.css custom properties, so ndt.css must still be loaded on the page. |
| `image-compare.js` | <a href="/downloads/image-compare.js" download="image-compare.js">Download</a> <small>1.6 KB</small> | A single delegated `input` listener that drives every `.image-compare` on the page — add it as `<script src="/js/image-compare.js">`, separate from global.js. |

The markup itself (see the code sample above) has no required JavaScript dependency beyond that one script — the slider is a native `<input type="range">`, so drag, tap, touch, and keyboard all work as soon as the script and stylesheet are present. `ImageCompare.js` in this repo is a Storybook/authoring convenience for generating that markup; it is not required on a site that hand-authors the HTML.

    <ul>

  <li>

    <ul>
      <li>Do not use images with different aspect ratios or crops.</li>

      <li>Do not use more than one Image Compare in the same view.</li>
    </ul>
  </li>

## Accessibility

- The slider is a native `input[type="range"]`: it is keyboard operable (arrow keys), and announces its position via `aria-valuetext`.
- Both images require `alt` text describing what each shows.
- The divider and handle are decorative (`aria-hidden`) — all interaction happens through the range input.

## CSS References

Defined in `css/image-compare.css`, not ndt.css — see Installing on a Site above.

| CSS Class                         | Description                                                                                   |
|-----------------------------------|-----------------------------------------------------------------------------------------------|
| `.image-compare`                  | Base class for the Image Compare figure; grid that stacks the layers.                         |
| `.image-compare-before`           | Top image, clipped to the divider position.                                                   |
| `.image-compare-after`            | Bottom image, fully visible.                                                                  |
| `.image-compare-input`            | Invisible range input that drives the interaction.                                            |
| `.image-compare-divider`          | Vertical divider line following the slider position.                                          |
| `.image-compare-handle`           | Circular drag handle with direction arrows.                                                   |
