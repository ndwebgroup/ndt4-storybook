## Accessibility

- The ring uses `role="meter"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, and `aria-valuetext` — the correct native pattern for a single bounded value, so assistive technology announces it without needing a data table.
- The centered value text is decorative (`aria-hidden`) since the same information is already exposed through `aria-valuetext`.
- Ring and track colors adapt to light and dark mode automatically.
