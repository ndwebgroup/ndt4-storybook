## Usage

<ul className="list--todo">
  <li>
    ### Dos
    <ul>
      <li>Sort categories in a meaningful order (chronological, largest-to-smallest) rather than alphabetically.</li>
      <li>Use Horizontal orientation when category labels are long.</li>
      <li>Use Stacked only when the sum of the series is itself meaningful.</li>
    </ul>
  </li>
  <li>
    ### Donts
    <ul>
      <li>Do not use more than 3–4 series in one chart; split into multiple charts instead.</li>
      <li>Do not truncate the value axis in a way that exaggerates differences.</li>
    </ul>
  </li>
</ul>

## Accessibility

- The chart's `<canvas>` has `role="img"` and an `aria-label` matching the title.
- A visually hidden `<table>` of the same labels and values is always rendered for screen reader users.
- Legend, axis, and tooltip colors adapt to light and dark mode automatically.
