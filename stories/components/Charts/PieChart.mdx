## Usage

<ul className="list--todo">
  <li>
    ### Dos
    <ul>
      <li>Order slices largest to smallest, starting at 12 o'clock.</li>
      <li>Use a Donut when you want to show a total value in the center (pair with a Stat Ring instead if there is only one number).</li>
    </ul>
  </li>
  <li>
    ### Donts
    <ul>
      <li>Do not use more than 5–6 slices; group small categories into "Other."</li>
      <li>Do not use a pie chart to compare values across multiple categories over time — use a Bar or Line Chart.</li>
    </ul>
  </li>
</ul>

## Accessibility

- The chart's `<canvas>` has `role="img"` and an `aria-label` matching the title.
- A visually hidden `<table>` of the same labels and values is always rendered for screen reader users.
- Tooltips show both the value and computed percentage; slice colors adapt to light and dark mode automatically.
