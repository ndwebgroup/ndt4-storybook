## Usage

<ul className="list--todo">
  <li>
    ### Dos
    <ul>
      <li>Use for continuous data over time — years, terms, months.</li>
      <li>Use Filled sparingly, and only for a single series; filled areas overlap and become unreadable with multiple series.</li>
    </ul>
  </li>
  <li>
    ### Donts
    <ul>
      <li>Do not use a line chart for unordered categories — use a Bar Chart instead.</li>
      <li>Do not use more than 3–4 series in one chart.</li>
    </ul>
  </li>
</ul>

## Accessibility

- The chart's `<canvas>` has `role="img"` and an `aria-label` matching the title.
- A visually hidden `<table>` of the same labels and values is always rendered for screen reader users.
- Legend, axis, and tooltip colors adapt to light and dark mode automatically.
