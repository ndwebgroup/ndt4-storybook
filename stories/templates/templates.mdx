# About Templates

Templates are complete, ready-to-use page layouts built from the components and collections in this kit. Use them as a starting point for a new page rather than assembling one from scratch.

## Using a Downloaded Template

Each download is a standalone HTML file with the template's markup, the icon and sticker sprites inlined, and a link to the externally hosted `ndt.css`. Before using one on a live site:

<ul className="list--todo">
  <li>
    ### Dos
    <ul>
      <li>Add <code>&lt;script src="/js/global.js"&gt;&lt;/script&gt;</code> to your site so interactive elements (menus, dialogs, the light/dark toggle) work.</li>
      <li>Replace the placeholder copy, images, and links with real content.</li>
      <li>Confirm the page still reflects the current version of the components it uses — templates are a snapshot at download time.</li>
    </ul>
  </li>
  <li>
    ### Donts
    <ul>
      <li>Don't ship the downloaded file as-is; it's a starting point, not a finished page.</li>
      <li>Don't remove the `#wrapper` id or the `nav-top--*` class — layout CSS depends on them.</li>
      <li>Don't fork component markup here instead of pulling updates from this kit; downloaded templates will drift from the source over time.</li>
    </ul>
  </li>
</ul>

## Best Practices

Start from the template that's closest to your page's purpose, then customize. If none of these fit, check <a href="/?path=/docs/collections-page-header-docs--docs">Page Headers</a> and the individual component docs to assemble a custom layout instead.
